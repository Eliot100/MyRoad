# Mobile pass at 360 and 412 px, Chrome on Android (2026-11-04, UI · UI UX dev)

## Context
Issue #233 (D27, Android requirement). Every learner screen must work at 360 and 412 CSS px: no horizontal scroll, 44x44 px touch targets, the soft keyboard never hides the focused field, RTL right in he and ar, en LTR. Stay in the UI layer: no route, store or content change. Coordinates with #218 (WCAG 2.2 AA).
DoD: a Playwright test in the a11y job checks each learner screen at 360x800 and 412x915 (touch, mobile) in he, ar and en; axe stays at 0 new violations; core and a11y suites green.

## Options considered
| Option | Pros | Cons | Score | Cost to switch later |
| A (chosen) CSS tap areas on the existing links and chips, an invisible hit circle on map tiles, a small visualViewport keep-in-view script, one CI test | Visible text stays the same size; one small CSS block; the test stops regressions | The test skips links inside running text (WCAG allows those) | 22/25 | - |
| B bigger visible buttons for every header link | Obvious targets | Heavier header, breaks the calm look at 1280 | 14/25 | low: CSS only |
| C a separate mobile template set | Full control | Two templates per screen to keep in sync | 10/25 | high |

## Decision
A. Header links (back, brand, settings, lock link), chips, sidebar subject tabs, the language switch, the skip link and the goal summaries get a 44 px tap area while the text keeps its size. Map tiles get an invisible circle so the target is 44 px or more after the map scales to the phone. The back arrow mirrors in LTR. When the soft keyboard opens, the focused input scrolls into view; the map keeps scroll padding under its sticky action bar.
Reuse: Playwright (already in the a11y job), browser visualViewport API. No new dependency.

## Verified
- tests_a11y: 25 passed, including test_mobile_360_412.py (he, ar, en).
- Audit script over 13 learner screens x 360/412 x he/en/ar: 0 horizontal scroll, 0 small stand-alone targets (before: skip link, header links, language buttons, chips, map tiles under 44 px).
- Screens: docs/ui/screens/233/, before/after in before-after/.

## Known limits
- The Netflix style rows on home scroll sideways by design; the page itself does not.
- Real device check on a Pixel is still manual (device mode and Playwright mobile viewports only).

## How to switch
To B: drop the min-block-size rules in the "Mobile pass, issue 233" block of platform.css and size the links as buttons.
