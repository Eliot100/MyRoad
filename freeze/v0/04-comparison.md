# השוואה: תוצאת Grok הראשונה מול טיוטת MyRoad v0

מסמך זה משווה את התוצאה הראשונה שנוצרה בצ'אט (פיגום גנרי) מול הארטיפקטים ב־`/workspace/myroad-v0/`, מול תלונות המשתמש ומול ארבעת מסמכי האפיון (חזון, אפיון מפורט, מימוש ובדיקות, לפני מימוש).

מזהה מוצר יציב באנגלית: **MyRoad**. שפת תוכן בדוגמה: עברית (`contentLanguage=he`). ממשק: `uiLocale=he-IL` — מופרדים במודל.

## טבלת תלונות

| תלונה | תוצאה ראשונה (Grok) | טיוטה זו (myroad-v0) |
|--------|---------------------|----------------------|
| בלוקים גנריים בלי הקשר לנושא | שלבי לימוד כלליים / תבניות בלי תוכן מתמטי אמיתי | גרף בלוקים על **משוואות ריבועיות** עם הגדרות, נוסחאות, תרגילים ותשובות מאומתות |
| אין תוכן ספציפי לנושא / מתמטיקה | חסר verified core; אין נוסחאות או פתרונות | `verifiedCore` עם \(ax^2+bx+c=0\), \(D=b^2-4ac\), נוסחת השורשים, פריטי תרגול/הערכה עם תשובות |
| חסרים שם ותיאור למסלול | נשמר בעיקר פרומפט סוכן; שם/תיאור חלשים או חסרים | `name`, `description`, `goal`, `audience`, `prerequisites` מלאים ב־JSON |
| אין חיפוש מקורות ואישור לפני בנייה | מקורות לא כשלב חובה עם `approved:false` | `sources[]` + `retrievalState` (אושר=false עד אדם); כלים `listSourcesForApproval` / `approveSources` |
| אין עריכה לכל שלב בזמן בנייה | פיגום קשיח / לא מודגש per-block edit | `blockId` יציב, `editable: true`, כלים `addBlock` / `editBlock` |
| ערבוב עברית/אנגלית בתגי UI | תגיות מעורבות; מעטפת לא עקבית | `contentLanguage` ו־`uiLocale` נפרדים; תוכן לימודי בעברית; מזהה מוצר MyRoad באנגלית בלבד |
| משוב לא יוצר גרסה עם diff ברור | מושג revise קיים ברמה כללית בלי דוגמת JSON | `02-…` עם `versionId` חדש, רשומת `feedback`, אובייקט `_diff` (בלוקים/קשתות ששונו ולמה) |
| פרסום אוטומטי / טשטוש draft↔published | סיכון לבלבול סטטוסים | `status=draft`; חוזה כלים אוסר auto-publish; published נשאר immutable |

## כיסוי מול ארבעת מסמכי האפיון

| מסמך | מה ננעל בטיוטה |
|------|----------------|
| 01 חזון ומטרה | לולאת POC: נושא → מקורות → טיוטה → למידה → משוב → תיקון → אדם מפרסם; מדידה ומסלול גרפי במקום צ'אט חופשי |
| 02 אפיון מפורט | מודל קנוני: path/block/edge/attempt/feedback/source; סוגי בלוקים וקשתות; הפרדת שפות; provenance |
| 03 מימוש ובדיקות | שני JSON קנוניים (לפני/אחרי משוב) + חוזה כלים — שלב 1 בשרשרת הבנייה המומלצת |
| 04 לפני מימוש | נעילות: enums, דוגמאות JSON+diff, חוזה כלים+RBAC, גבול verified/generative, מדיניות מקורות ופרסום |

## מה עדיין נדחה במכוון (לא בפאזה 0)

- אופטימיזציית A/B אוטומטית על לומדים (במיוחד קטינים)
- תקשורת עשירה בין תפקידים (הודעות מורה–תלמיד מלאות)
- ויזואליזציית גרף תלת־ממדית / מרהיבה
- מערכות סיפור/דמות מותאמות אישית
- כיסוי מלא עברית+ערבית+אנגלית כהוראה סימולטנית
- ספריית תוכן שלמה מאפס עד בגרות
- אפליקציית הורים / רגולציית בית־ספר מלאה
- יצירת וידאו / ניסויי UI מתקדמים
- מיגרציה אוטומטית של לומדים באמצע מסלול לגרסה חדשה (רק הערה במודל)

## סיכום קצר

הטיוטה מתקנת את הפיגום הגנרי במסלול זהב קונקרטי בעברית, עם מקורות לאישור, עריכה לפי בלוק, הפרדת שפות, וגרסת משוב עם diff — בלי לטעון שכבר מומש מנוע למידה או UI מלא.
